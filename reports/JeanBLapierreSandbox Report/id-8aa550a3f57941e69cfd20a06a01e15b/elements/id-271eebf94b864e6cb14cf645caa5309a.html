P1: Maximize the use of the core Benefit Delivery Platform technology​ ()
Principle 1: Maximize the use of the core Benefit Delivery Platform technology​ BDM follows the Right Solution Selection Guidance for Benefit Delivery Capabilities​ 1. If Cúram support the capability and meets the needs, use Cúram. Otherwise,​ 2. If ESDC (or GC) has an enterprise solution that is sustainable and scalable, not considered legacy, not on the list for Technical Debt Remediation, and does not hinder modernization, use the enterprise solution. Otherwise, 3. If a technology to build a new solution is available on the market, procure the technology and build a new solution. Otherwise,​ 4. Build a custom (bespoke) solution specifically for BDM (or ESDC). Ensure that ESDC has the budget, capacity and skills to support and evolve the solution once its built. Rationale: BDM shall bring new technologies and innovations that are needed for modernizing benefit delivery. BDM should, at the same time, maximize return on investments and reuse existing solutions where they are fit for purpose. And, finally, BDM needs to be able to prevent Tech Sprawl, i.e. overbuying technology or buying multiple similar tools for the same purpose. Implications: • When evaluating options for new solutions, Architecture team will provide recommendations following this principle. • If building a new solution may present opportunity to enhance or modernize enterprise solution(s), such opportunities will be identified as architecture options and presented to BDM ARC for endorsement and EARB for approval. • The guidance is expected to be followed by BDM partners - Qualified Supplier Working Group.
