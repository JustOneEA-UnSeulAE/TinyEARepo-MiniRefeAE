A8.02.04 Data Mapping [DACM] ()
A8.02.04 Data Mapping Software that supports the process of creating data element mappings between two distinct data models. Data mapping is used as a first step for a wide variety of data integration tasks. A8.02.04 Mise en correspondance des données Logiciel qui prend en charge le processus de création de mises en correspondance d’éléments de données entre deux modèles de données distincts. La mise en correspondance des données représente la première étape dans le cadre d’un large éventail de tâches d’intégration des données.
