A8.03.05 RESTful APIs
RESTful APIs do not require XML-based Web service protocols (SOAP and WSDL) to support their interfaces as they use HTTP. Representational State Transfer (REST) is a style of software architecture for distributed hypermedia systems such as the World Wide Web.
Unlike SOAP-based Web services, there is no official standard for RESTful Web APIs. This is because REST is an architectural style, while SOAP is a protocol. REST is not a standard in itself, but RESTful implementations make use of standards, such as HTTP, URI, JSON, and XML.

A8.03.05 API actives (RESTful)
Les API actives (RESTful) n’ont pas besoin de protocoles de service Web fondés sur le langage XML (SOAP et WSDL) pour prendre en charge leurs interfaces lorsqu’elles utilisent le protocole HTTP. Le transfert d’état représentationnel (REST) est un style d’architecture logicielle propre aux systèmes d’hypermédias distribués tels que le World Wide Web.  Contrairement aux services Web fondés sur le SOAP, il n’existe pas de norme officielle sur les API Web actives. En effet, le REST est un style architectural, tandis que le SOAP est un protocole. Le REST n’est pas une norme en soi, mais les implémentations RESTful s’appuient sur des normes telles que HTTP, URI, JSON et XML.
