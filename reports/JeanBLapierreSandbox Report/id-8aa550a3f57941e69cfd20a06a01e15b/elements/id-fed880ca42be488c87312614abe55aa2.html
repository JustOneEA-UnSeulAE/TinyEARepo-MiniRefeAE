A8.04.08 Managed File Transfer (MFT)
Managed file transfer (MFT) refers to a software or a service that manages the secure transfer of data from one computer to another through a network (e.g., the Internet). MFT software is marketed to corporate enterprises as an alternative to using ad-hoc file transfer solutions, such as FTP, HTTP and others.
Typically, MFT offers a higher level of security and control than FTP. Features include reporting (e.g., notification of successful file transfers), non-repudiation, auditability, global visibility, automation of file transfer-related activities and processes, end-to-end security, and performance metrics/monitoring.
MFT applications are available as both on-premises licensed software packages and software-as-a-service (SaaS). Some are specially designed for enterprise use while others are for sale to individual consumers. A few enterprise-focused SaaS MFT providers also manage the additions of new trading partners, which can free up a lot of IT (Information Technology) resources.

Related term: File Transfer Gateway, File Transfer Protocol (FTP) Gateway, FTP Server, File Exchange Gateway, Secure File Transfer Gateway.

A8.04.08 Transfert de fichiers gérés (MTF)
Le transfert de fichiers gérés (MTF) désigne un logiciel ou un service qui gère le transfert sécurisé des données d’un ordinateur à un autre par l’entremise d’un réseau (p. ex., Internet). Le logiciel de MFT est présenté aux entreprises comme étant une alternative à l’utilisation de solutions de transfert de fichiers ponctuelles, comme FTP, HTTP et autres.  En général, le MFT offre un niveau de sécurité et de contrôle plus élevé que le protocole FTP. Les caractéristiques du MFT comprennent la production de rapports (p. ex., notification de transferts de fichiers réussis), la non-répudiation, la vérifiabilité, la visibilité mondiale, l’automatisation des activités et des processus liés au transfert de fichiers, la sécurité de bout en bout et la mesure et la surveillance du rendement.  Les applications de MFT sont disponibles à la fois sous forme de progiciels sous licence sur les lieux et de logiciel en tant que service (SaaS). Certaines applications sont spécialement conçues pour être utilisées en entreprise, tandis que d’autres sont destinées à la vente à des consommateurs individuels. Quelques-uns des fournisseurs de SaaS de MFT qui concentrent leurs activités sur le secteur des entreprises proposent également un service de gestion et d’ajout de nouveaux partenaires commerciaux, ce qui permet de dégager une quantité importante de ressources de TI (technologies de l’information).  Source : Wikipédia.    Termes connexes : passerelle de transfert de fichiers, passerelle FTP, serveur FTP, passerelle d’échange de fichiers, passerelle de transfert de fichiers sécurisée.
