A8.03.03 API [DACM] ()
A8.03.03 API Software components that use an application programming interface (API) to communicate with each other.  May include specifications for routines, data structures, object classes, and variables. A8.03.03 API Composants logiciels qui utilisent une interface de programmation d’applications (API) pour communiquer entre eux.  Les renseignements communiqués peuvent comprendre des spécifications relatives aux routines, des structures de données, des classes d’objets et des variables.
